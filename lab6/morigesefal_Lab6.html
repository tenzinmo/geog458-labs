Data and methods

Existing supplied file, version field September 16, 2020. Historical values, not a live feed. Current Canvas download byte identity remains unverified.

All 39 values for 2020 match the estimates in the Washington DOH report, p. 80, which cites Washington OFM’s April 1, 2020 Population Trends. The Port of Seattle, Table F-1, also identifies the matching state, King, Pierce and Snohomish figures as April 1 estimates from OFM.

The estimate total is 7,656,200. The 2020 Census count is 7,705,281. These are different measures.

The original source and processing history of the course file remain unverified. Earlier county values were not independently verified; its statewide sums for 2001–2009 differ from DOH’s historical table. The chart and percentage change retain the supplied values.

Change = 100 × (POP2020 − POP2000) ÷ POP2000, using course-file values. For several counties, values are summed before computing change. Map colors describe each county separately. People added is POP2020 minus POP2000. Each comparison bar uses the largest county value for its measure as the full width. Ranks run from highest to lowest across the 39 counties.
